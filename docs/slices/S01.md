## Build
Create `lib/scoring.ts` exporting pure, deterministic functions:
- `scoreQuiz(answers: QuizAnswer[])` → `{ primary: LoveStyleId; hybridWith: LoveStyleId | null; isRojak: boolean; display: string; counts: Record<LoveStyleId, number> }`.
  - Each answer adds 1 to its style (A→sayang … E→hug).
  - Single top → `{ primary, hybridWith:null, isRojak:false, display:"<Name>" }`.
  - Two-way tie (2+2+1) → `primary` = tied style whose answer appears **earliest** in `answers`; `hybridWith` = the other; `display` = "<Primary>, with a bit of <Other>".
  - Five-way tie (1×5) → `isRojak:true`; counted `primary` = earliest-answered style; `display` = "Rojak Love".
- `familyMix(members: { primary: LoveStyleId; role: Role }[])` → `{ counts: Record<LoveStyleId, number>; distinct: number; archetype: 'dominant'|'contrast'|'rojak'|'twoway'; dominantStyle?: LoveStyleId; contrast?: {parents: LoveStyleId; children: LoveStyleId}; headline: string }` for N≥2.
  - Only the `primary` counts. Archetype, first match wins: (1) **dominant** — one style is the strict max AND ≥ ceil(N/2); (2) **contrast** — ≥1 parent-figure (Parent/Grandparent/Guardian) AND ≥1 child (Child) AND the two groups' dominant styles differ (group-dominant ties broken by earliest member index); (3) **rojak** — ≥3 distinct styles; (4) **twoway** — exactly 2 styles tied.
- Add a `Role` type (`'parent'|'child'|'grandparent'|'guardian'|'other'`) here or in `lib/love-styles.ts` import — keep it minimal; do not restructure love-styles.
