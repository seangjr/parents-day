## Build
- `lib/led-orchestrator.ts` — **pure reducer**: event state (mode, queued submissions since cursor,
  aggregates, families, recently-revealed) → directive `{ mode, payload }`. Modes map to the LED
  screens: `cluster-wall` (LED 1/2, base), `active-join` (LED 3, individual reveal),
  `family-mix` (LED 4, family reveal), `stats` (LED 5, dashboard), plus `welcome/idle` (QR).
  Encode ADR-0004 priority + cadence + throttle + flood/montage. Deterministic; unit-test in
  `lib/led-orchestrator.test.ts`.
- `app/api/led-state/route.ts` — GET `?cursor=N` → `{ cursor, newSubmissions, aggregates, families, mode }`
  from the repo (mode read from a Redis flag, default "live").
- `app/led/page.tsx` + client — polls `/api/led-state` every ~1–2s, feeds the orchestrator, renders the
  current mode matching the corresponding Figma LED screen using `components/led/*` + odometer.
  Never blanks; on poll failure holds last frame and resyncs from cursor. Kiosk/fullscreen.
