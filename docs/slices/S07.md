## Build
- `lib/led-orchestrator.ts` — a **pure reducer**: given event state (mode, queued submissions since cursor, aggregates, recently-revealed families) → the current directive `{ mode, payload }`. Encode ADR-0004 priority + cadence + throttle + flood/montage. Deterministic; unit-tested in `lib/led-orchestrator.test.ts`.
- `app/api/led-state/route.ts` — GET `?cursor=N` → `{ cursor, newSubmissions, aggregates, families, mode }` from the repo (mode read from a Redis flag, default "live").
- `app/led/page.tsx` + client — polls `/api/led-state` every ~1–2s, feeds the orchestrator, renders the current mode using `components/led/*` + odometer for numbers. Never blanks; on poll failure holds last frame and resyncs from cursor. Kiosk-friendly (fullscreen, wake-lock optional).
